# MAC BEAUTY 웹사이트

화장품 브랜드의 메인 페이지, 상품 목록, 로그인·회원가입, 장바구니 흐름을 구현한 웹 퍼블리싱 프로젝트입니다.  
브랜드 중심의 시각적 구성과 함께 폼 유효성 검사, 상품 수량 관리, 결제 금액 계산 등 실제 쇼핑몰에서 필요한 사용자 상호작용을 구현했습니다.

> 개인 학습용으로 제작한 비상업적 클론 프로젝트이며, 브랜드 및 이미지의 권리는 각 원저작권자에게 있습니다.

## 주요 기능

### 메인 배너 슬라이드

- 여러 배너를 일정 시간마다 자동으로 전환합니다.
- 재생·일시정지 버튼으로 자동 전환 상태를 제어합니다.
- 현재 배너 위치에 맞춰 진행 표시를 갱신합니다.

### 아코디언 메뉴와 모바일 검색

- 메뉴 항목을 펼치고 접을 수 있는 아코디언 내비게이션을 구성했습니다.
- 모바일 화면에서 별도의 검색 UI와 추천 검색어를 제공합니다.

### 로그인·회원가입 유효성 검사

- 이메일, 비밀번호, 이름, 휴대전화 입력값을 항목별로 검사합니다.
- 유효하지 않은 입력에는 테두리와 오류 메시지를 표시합니다.
- 비밀번호 표시·숨김 기능과 입력 중 실시간 검증을 구현했습니다.

### 상품 목록과 상세 화면

- 카테고리와 필터 값에 따라 상품 목록을 구성합니다.
- 상품 이미지 전환, 호버 효과, 컬러 옵션 등 쇼핑 UI를 구현했습니다.

### 장바구니 상태 관리

- 선택한 상품을 `localStorage`에 저장해 페이지 이동 후에도 유지합니다.
- 상품별 수량 증가·감소, 개별 삭제, 선택 삭제를 지원합니다.
- 선택된 상품의 수량과 가격을 기준으로 주문 금액을 자동 계산합니다.
- 장바구니가 비었을 때 별도의 빈 상태 화면을 표시합니다.

## 페이지 구성

```text
zs_web_2/
├── index.html             # 메인 페이지
├── html/
│   ├── login.html         # 로그인·회원가입
│   ├── detail.html        # 상품 목록·상세
│   └── cart.html          # 장바구니
├── css/                   # 페이지별 스타일
├── js/                    # 메뉴, 폼 검증, 상품, 장바구니 로직
├── image/                 # 상품 이미지와 아이콘
├── style.css              # 메인 스타일
└── script.js              # 메인 배너와 프로모션 슬라이드
```

## 실행 방법

별도의 설치 과정 없이 저장소를 내려받은 후 `index.html`을 브라우저에서 열면 실행할 수 있습니다.

```bash
git clone https://github.com/zlse226/zs_web_2.git
cd zs_web_2
```

## 구현하며 배운 점

- 폼 입력값 검증과 사용자 친화적인 오류 표시
- 이벤트 위임을 활용한 동적 장바구니 요소 제어
- `localStorage`와 JSON을 이용한 브라우저 상태 저장
- 수량과 선택 상태에 따른 결제 금액 자동 계산
- 데스크톱과 모바일 UI를 고려한 반응형 퍼블리싱

## 개선 계획

- 실제 API를 연동한 상품 검색·필터링
- 장바구니 데이터 구조와 중복 상품 처리 개선
- 폼 접근성과 키보드 탐색 보완
- 반복되는 헤더·메뉴 마크업의 컴포넌트화
- 이미지 최적화와 로딩 성능 개선
